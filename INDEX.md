## ✅ Quick Reference

### **Local Development**
```bash
# Start
docker-compose up -d
go run main.go

# Test
go test ./...

# Playground
http://localhost:8080
```

### **Production Deploy**
```bash
# Build
docker build -t turtle:latest .

# Deploy
kubectl apply -f k8s/

# Monitor
kubectl logs -f deployment/turtle-api
```

### **Common Queries**
```graphql
# Health
query { health }

# Profile
query { me { id firstName } }

# Addresses
query { myAddresses { id label } }
```
